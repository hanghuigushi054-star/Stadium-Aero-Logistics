# Stadium Weather Radar (球場局地気象レーダー)

本アプリケーションの技術スタック、使い方、および開発の背景・目的を以下にまとめます。

##　　概要
全国の主要プロ野球場上空の気象環境をリアルタイムに解析し、天候が試合に与える影響をシミュレート・可視化するモニターダッシュボードです。SF・サイバーパンクテイストのUIを採用し、環境データとベースボール・ダイナミクスを融合させた独自のアナリティクス体験を提供します。

## 技術スタック (Tech Stack)

*   **Frontend Framework:** React 18
*   **Language:** TypeScript
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS (サイバーパンク・ダークテーマ)
*   **Icons:** Lucide React
*   **Visualization:** SVG & CSS Animations (風向のベクター表現等)

## 使い方 (How to use)

1.  **球場の選択:** 画面左上のドロップダウンメニューから、現在の状況を知りたいプロ野球の球場（ZOZOマリンスタジアム、甲子園、神宮など）を選択します。
2.  **局地気象の確認:** 選択した球場における現在の気温、湿度、風速、および風冷却を考慮した「体感温度」が表示されます（※現在は乱数を用いたシミュレーションデータです）。
3.  **風向ベクトルの視認:** 画面中央の「グラウンド風向ベクトル」に、ホームベースを基準とした風の向きと強さがリアルタイムなアニメーションとして表示されます。赤い風は「強風」を示し、フライの軌道などに影響が出る目安となります。
4.  **気象アラート:** 各球場の特性や状態に応じて、「海風注意」や「強風警報」などの局地気象アラートが画面上部に自動的に表示されます。

## 【解決策とシステム化の目的】

**目的:** 
球場という局地的な環境で発生する気象条件（特に「風」）をリアルタイムに可視化し、ファンやプレイヤーの野球観戦・分析体験を向上させること。

**解決策:** 
従来の一般的な天気予報アプリでは、「XX市の天気」という広域データしか分からず、スタジアム内部のグラウンドレベルでの風の流れはわかりませんでした。本システムは、グラウンド図に直接ベクトル（矢印）を重ねる直感的なレーダーUIを採用することで、「今はライトからレフトへ強い風が吹いているから、右打者の打球が伸びにくい」といった、野球のプレイングに直結する情報を視覚的に提供します。

## 開発の背景と着眼点

**開発の背景:** 
野球は天候、とりわけ「風」に極めて大きな影響を受けるスポーツです。ZOZOマリンスタジアムの「マリン風」や阪神甲子園球場の「浜風」、横浜スタジアムの独特な風の舞い方など、各球場には名物となる風が存在します。ファン同士でも「今日の風ならあの打球は入っていた」といった会話が日常的に交わされますが、それを客観視・共有する専門のダッシュボードが不足していると考えたのが開発のスタートです。

**着眼点:**
1.  **屋外スタジアムでの視認性 (Visibility):** 野球観戦は屋外やナイターで行われることが多いため、暗い場所でも眩しすぎず、かつ情報がくっきりと浮かび上がる高コントラストなダーク・サイバーパンク風UIに着目しました。
2.  **球場ごとの物理的特性の反映 (Stadium Physics):** 全ての球場を同じ条件で扱うのではなく、海沿いの球場（海風要素）やドーム球場（風速がゼロになる要素）など、各球場のアーキテクチャや立地特性をロジックの根底に組み込みました。これにより、エスコンフィールド等を選択した際は環境の影響を受けない点などが正確に表現されます。
3.  **直感へのフォーカス (Intuitive Design):** 風向を「北北西」といった文字だけで伝えるのではなく、野球ファンが普段見慣れている「ホームベースからセンター方向への視点」の図面に落とし込むことで、認知負荷を極限まで下げるアプローチを取りました。
