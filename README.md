# Stadium Aero-Logistics

## 概要 (Overview)
本アプリは、プロ野球の各球場エリアで発生している局地的な気象情報（風・気温・湿度・体感温度）のモニタリングに特化したダッシュボードです。
打球の行方や観戦環境に大きく影響する「スタジアムにおける風の振る舞い」を、直感的かつリアルタイムに視覚化することを目的としています。


## 開発の背景と着眼点
* **背景：** 野球において「風」は試合を左右する極めて重要なファクターです（例：ZOZOマリンスタジアムの「マリン風」、甲子園の「浜風」など）。しかし、観客が今のグラウンドの風力・風向を正確かつ直感的に把握する手段はこれまで乏しく、球場で旗を見上げるしかありませんでした。
* **集中：**
1. **屋外・ナイター環境での視認性:**  スタジアムの屋外観戦中や夜間でも見やすいよう、眩しさを抑えつつ情報が浮き出るダークモード＆高コントラストUIを採用。
2. **グラウンド目線での直感的なUI:** 風向を「北西」といった方角のテキストではなく、「野球場の図面（ホームからバックスクリーンへの向き）」に直接ベクトルを重ねることで、どの方向へ打球が流されるか一目でわかるようにしました。
3. **球場ごとのパーソナライズ:** ドーム球場（エスコンフィールドなど）を選択した場合は無風になるなど、各球場の実態に合わせたロジックを組み込む点に着目しています。

## 解決策とシステム化の目的
目的： 球場という特殊な環境下で発生する「局地的な気象条件（特に風）」をリアルタイムで可視化し、野球観戦の没入感と分析の楽しさを向上させること。
解決策の決定： 一般的な天気予報アプリの「XX市の天気」ではカバーしきれない、グラウンドレベルでの風の向きを野球専用のレーダーUIで直感的に表示。球場ごとの特性（ドームか屋外か、海沿いかなど）を考慮し、試合展開に直結する環境要因をシステム化して提供します。

## 主な機能 (Features)
* **グラウンド風向ベクトルの視覚化（レーダー）**
  *単なる数値だけでなく、スタジアム中心から「どちらに・どれくらいの強さで」風が吹いているかをレーダーUI上に矢印ベクトルとしてリアルタイムに描画します。
  *風速が強くなる（8m/s以上等）とエフェクトが変化（オレンジ色化）し、直感的に強風を察知できます。
* **局地気象概況と体感温度の自動計算**
  *現在の気温・湿度・風速・風向（16方位）を常時監視します（現在はモックデータが揺らぐ仕組みです）。
  *風速を考慮した**「体感温度（風冷却）」**を自動計算し、実際の気温よりも体感がどれだけ寒いかをリアルに算出します。
* **スタジアム特性に合わせた環境アラート**
  *選択した球場固有の環境条件（海風の有無、風速係数など）に基づき、アラートを自動判定します。
*例:** ZOZOマリンスタジアムでの「海風警戒」、強風下での「飛球影響注意」など、観戦者およびプレイに影響する要素をテキストで警告します。
サイバーパンク/ミリタリー調のUIデザイン
屋外での日差しの中やナイター時でも視認性が高い、ダークモードを基調とした高コントラストなUIを採用しています。


## 技術スタック (Tech Stack)
* **フロントエンドフレームワーク：** React 18
* **言語：** TypeScript
* **ビルドツール:** 素早く
* **スタイリング：** Tailwind CSS (サイバーパンク/ダークテーマによる高コントラストUI)
* **アイコン:** ルシド・リアクト
* **視覚化：** SVG & CSS Animations (レーダーおよび風向ベクトル表現)

## 使い方 (How to use)
1. **球場の選択:** 画面左上のプルダウンメニューから、現在の状況を知りたいプロ野球の球場（ZOZOマリンや甲子園など）を選択します。
2. **局地気象の確認:** 球場ごとの現在の気温、風速、風向、湿度、および体感温度が表示されます。
3. **風向ベクトルの視認:** 風向ベクトルの視認: 画面中央の「グラウンド風向ベクトル」に、ホームベースを基準とした風の向きと強さがアニメーションで表示されます。（強風時は色が変化します）。
4. **アラート確認:** 風の強さや球場の特性（海風など）に応じた局地気象アラートが画面上部に表示されます。
